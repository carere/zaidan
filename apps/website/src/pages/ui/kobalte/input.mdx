## Field

Use `Field`, `FieldLabel`, and `FieldDescription` to create an input with a label and description.

<ComponentPreview name="input-field" previewClass="*:max-w-xs" />

## Field Group

Use `FieldGroup` to show multiple `Field` blocks and to build forms.

<ComponentPreview name="input-fieldgroup" previewClass="*:max-w-xs" />

## Disabled

Use the `disabled` prop to disable the input. To style the disabled state, add the `data-disabled` attribute to the `Field` component.

<ComponentPreview name="input-disabled" previewClass="*:max-w-xs" />

## Invalid

Use the `aria-invalid` prop to mark the input as invalid. To style the invalid state, add the `data-invalid` attribute to the `Field` component.

<ComponentPreview name="input-invalid" previewClass="*:max-w-xs" />

## File

Use the `type="file"` prop to create a file input.

<ComponentPreview name="input-file" previewClass="*:max-w-xs" />

## Inline

Use `Field` with `orientation="horizontal"` to create an inline input. Pair with `Button` to create a search input with a button.

<ComponentPreview name="input-inline" previewClass="*:max-w-xs" />

## Grid

Use a grid layout to place multiple inputs side by side.

<ComponentPreview name="input-grid" previewClass="p-6" />

## Required

Use the `required` attribute to indicate required inputs.

<ComponentPreview name="input-required" previewClass="*:max-w-xs" />

## Badge

Use `Badge` in the label to highlight a recommended field.

<ComponentPreview name="input-badge" previewClass="*:max-w-xs" />

## Input Group

To add icons, text, or buttons inside an input, use the `InputGroup` component. See the [Input Group](/docs/components/kobalte/input-group) component for more examples.

`Input` is a styled native input element. See the [HTML input element reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) for its native props, keyboard behavior, and accessibility semantics.
