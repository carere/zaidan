The `Message` component provides the layout primitives around conversational content. Combine it
with `Bubble`, avatars, headers, footers, and `MessageGroup` for complete chat transcripts.

## Usage

```tsx showLineNumbers
import { Message, MessageContent } from "~/components/ui/message";
import { Bubble, BubbleContent } from "~/components/ui/bubble";
```

```tsx showLineNumbers
<Message align="end">
  <MessageContent>
    <Bubble><BubbleContent>Thanks!</BubbleContent></Bubble>
  </MessageContent>
</Message>
```

## Composition

Use `MessageAvatar`, `MessageHeader`, and `MessageFooter` to add context around the message
content. Use `MessageGroup` for consecutive messages from the same participant.
