## Usage

```tsx showLineNumbers
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
} from "~/components/ui/combobox";

const frameworks = ["Next.js", "SvelteKit", "Nuxt.js", "Remix", "Astro"];
```

```tsx showLineNumbers
<Combobox
  options={frameworks}
  placeholder="Select a framework..."
  itemComponent={(props) => (
    <ComboboxItem item={props.item}>{props.item.rawValue}</ComboboxItem>
  )}
>
  <ComboboxInput placeholder="Select a framework..." />
  <ComboboxContent>
    <ComboboxEmpty>No frameworks found.</ComboboxEmpty>
  </ComboboxContent>
</Combobox>
```

See the [Kobalte Combobox documentation](https://kobalte.dev/docs/core/components/combobox) for primitive-level options, accessibility, and keyboard behavior.

## Composition

### Simple

A single-line input and a flat list rendered from `options` via `itemComponent` (see [Basic](#basic)).

```text
Combobox
├── ComboboxInput
└── ComboboxContent
    └── ComboboxEmpty
```

### With Groups

Group `options` with `optionGroupChildren`, and render a section heading (and an optional separator) from `sectionComponent` (see [Groups](#groups)).

```text
Combobox
├── ComboboxInput
└── ComboboxContent
    └── ComboboxEmpty

sectionComponent renders, per group:
├── ComboboxSeparator (optional, skipped for the first group)
└── ComboboxSection
    └── ComboboxSectionLabel
```

## Custom Items

Use `optionValue` and `optionTextValue` when your options are objects.

```tsx showLineNumbers
type Framework = {
  label: string;
  value: string;
};

const frameworks: Framework[] = [
  { label: "Next.js", value: "next" },
  { label: "SvelteKit", value: "sveltekit" },
  { label: "Nuxt", value: "nuxt" },
];

<Combobox
  options={frameworks}
  optionValue="value"
  optionTextValue="label"
  placeholder="Select a framework..."
  itemComponent={(props) => (
    <ComboboxItem item={props.item}>{props.item.rawValue.label}</ComboboxItem>
  )}
>
  <ComboboxInput placeholder="Select a framework..." />
  <ComboboxContent>
    <ComboboxEmpty>No frameworks found.</ComboboxEmpty>
  </ComboboxContent>
</Combobox>
```

## Multiple Selection

Use `multiple` (with a `T[]` `value`/`defaultValue`) for multi-select behavior. Selected options appear as removable chips in `ComboboxInput` and remain visible while you type or open and close the list. Each remove button is keyboard focusable and named for its option; removing the last chip leaves an empty input. Controlled `value` updates and `onChange` use the same selection API. Disabled controls keep their chips visible and prevent removal. For object options, configure `optionTextValue` for chip labels.

```tsx showLineNumbers
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
} from "~/components/ui/combobox";

<Combobox
  options={frameworks}
  placeholder="Select frameworks..."
  multiple
  defaultValue={[frameworks[0]]}
  itemComponent={(props) => (
    <ComboboxItem item={props.item}>{props.item.rawValue}</ComboboxItem>
  )}
>
  <ComboboxInput placeholder="Select frameworks..." />
  <ComboboxContent>
    <ComboboxEmpty>No frameworks found.</ComboboxEmpty>
  </ComboboxContent>
</Combobox>
```
