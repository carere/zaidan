## Disabled

Add the `disabled` prop to `Switch` to disable it. Add `data-disabled` to `Field` for disabled styling.

<ComponentPreview name="switch-disabled" />

## Invalid

Add `aria-invalid` to `Switch` to indicate an invalid state. Add `data-invalid` to `Field` for styling.

<ComponentPreview name="switch-invalid" />

## API Reference

`Switch` is a native Solid composition that implements the [WAI-ARIA switch role](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/switch_role), including keyboard, disabled, and form behavior.
