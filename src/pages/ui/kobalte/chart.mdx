# Chart

Composable chart primitives built with [Solid Recharts](https://github.com/yumemi-thomas/solid-recharts). The wrapper adds shadcn-compatible colors, configuration, tooltips, and legends while keeping the chart itself fully composable.

Browse the complete collection on the [Charts page](/charts/area).

## Installation

### CLI

```package-dlx
shadcn@latest add @zaidan/chart
```

### Manual

Install the SolidJS 1.x-compatible release:

```package-install
solid-recharts@1.0.0
```

Copy and paste the component into your project.

```tsx file=../../../registry/kobalte/ui/chart.tsx showLineNumbers

```

### Vite

`solid-recharts@1.0.0` publishes Solid TSX source. Exclude it from Vite's client and SSR dependency optimizers so `vite-plugin-solid` compiles that source:

```ts title="vite.config.ts"
import { defineConfig } from "vite";

export default defineConfig({
  optimizeDeps: {
    exclude: ["solid-recharts"],
  },
  ssr: {
    noExternal: ["solid-recharts"],
    optimizeDeps: {
      exclude: ["solid-recharts"],
    },
  },
});
```

## Chart config

`ChartConfig` maps data keys to their display labels, icons, and colors. Colors become scoped CSS variables such as `--color-desktop`.

```tsx
import type { ChartConfig } from "~/components/ui/chart";

const chartConfig = {
  desktop: {
    label: "Desktop",
    color: "var(--chart-1)",
  },
  mobile: {
    label: "Mobile",
    theme: {
      light: "oklch(0.646 0.222 41.116)",
      dark: "oklch(0.488 0.243 264.376)",
    },
  },
} satisfies ChartConfig;
```

## Usage

Compose Solid Recharts primitives inside `ChartContainer`.

```tsx
import { Area, AreaChart, CartesianGrid, XAxis } from "solid-recharts";
import {
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
} from "~/components/ui/chart";

<ChartContainer config={chartConfig}>
  <AreaChart data={chartData} accessibilityLayer>
    <CartesianGrid vertical={false} />
    <XAxis dataKey="month" tickLine={false} axisLine={false} />
    <ChartTooltip
      cursor={false}
      content={(props) => <ChartTooltipContent {...props} />}
    />
    <Area
      dataKey="desktop"
      fill="var(--color-desktop)"
      stroke="var(--color-desktop)"
    />
  </AreaChart>
</ChartContainer>
```

:::note[Solid content callbacks]
Pass tooltip and legend content as a function. Solid Recharts uses the function to inject the active payload into your component.
:::

## Tooltip

`ChartTooltipContent` understands the chart config and supports dot, line, and dashed indicators.

```tsx
<ChartTooltip
  content={(props) => (
    <ChartTooltipContent
      {...props}
      indicator="dashed"
      labelFormatter={(value) => String(value)}
    />
  )}
/>
```

Useful props include `hideLabel`, `hideIndicator`, `indicator`, `nameKey`, `labelKey`, `color`, `class`, and `labelClass`.

## Legend

```tsx
import { ChartLegend, ChartLegendContent } from "~/components/ui/chart";

<ChartLegend
  content={(props) => <ChartLegendContent {...props} />}
/>
```

Use `nameKey` to resolve a different config key or `hideIcon` to render color swatches instead of configured icons.

## Accessibility

Set `accessibilityLayer` on the Solid Recharts chart component to enable keyboard navigation and screen-reader descriptions.

```tsx
<AreaChart accessibilityLayer data={chartData}>
  {/* ... */}
</AreaChart>
```
