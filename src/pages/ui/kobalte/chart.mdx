The Chart component ports shadcn's composition-first chart helpers to Solid 1 and
[`solid-recharts`](https://www.npmjs.com/package/solid-recharts). It provides a responsive
container, scoped color variables, and shadcn-shaped tooltip and legend content while leaving the
chart primitives directly available from `solid-recharts`.

## Installation

```bash
bunx shadcn@latest add @zaidan/chart
```

The registry item installs the pinned chart dependency:

```bash
bun add solid-recharts@1.0.0
```

## Chart Configuration

Define human-readable labels and chart color tokens in a `ChartConfig`:

```tsx
import type { ChartConfig } from "@/registry/kobalte/ui/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    color: "var(--chart-1)",
  },
} satisfies ChartConfig
```

## Composition

Compose the Solid chart primitives inside `ChartContainer`:

```tsx
import { Area, AreaChart, CartesianGrid, XAxis } from "solid-recharts"
import {
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
} from "@/registry/kobalte/ui/chart"

<ChartContainer config={chartConfig} class="min-h-[300px] w-full">
  <AreaChart accessibilityLayer data={chartData}>
    <CartesianGrid vertical={false} />
    <XAxis dataKey="month" tickLine={false} axisLine={false} />
    <ChartTooltip
      cursor={false}
      content={(tooltipProps) => (
        <ChartTooltipContent {...tooltipProps} indicator="line" />
      )}
    />
    <Area
      dataKey="desktop"
      fill="var(--color-desktop)"
      stroke="var(--color-desktop)"
    />
  </AreaChart>
</ChartContainer>
```

Custom tooltip and legend content use function-form renderers. Solid does not clone a pre-created
JSX element to inject the active payload, so React's `content={<ChartTooltipContent />}` form does
not carry the runtime tooltip props in `solid-recharts@1.0.0`.

## Theming

Use either a single color or light/dark values. `ChartContainer` scopes the resulting
`--color-*` variables to the chart instance and follows Zaidan's `data-kb-theme` attribute.

```tsx
const chartConfig = {
  revenue: {
    label: "Revenue",
    theme: {
      light: "oklch(0.646 0.222 41.116)",
      dark: "oklch(0.488 0.243 264.376)",
    },
  },
} satisfies ChartConfig
```
