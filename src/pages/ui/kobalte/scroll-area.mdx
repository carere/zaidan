```text

```

## API Reference

### ScrollArea

The root container that measures overflow and coordinates the viewport and scrollbars.

| Prop | Type | Default |
| --- | --- | --- |
| `overflowEdgeThreshold` | `number \| Partial<Record<"xStart" \| "xEnd" \| "yStart" \| "yEnd", number>>` | `0` |
| `class` | `string` | - |

### ScrollBar

A scrollbar track and thumb for one axis. Renders only while its axis overflows, unless `keepMounted` is set.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `keepMounted` | `boolean` | `false` |
| `class` | `string` | - |

ScrollArea is a native SolidJS implementation and does not build on a Kobalte or Corvu primitive, so it does not expose a primitive API to link to.
