The `Marker` component renders compact status and activity rows for timelines, assistant output,
and system events. Compose it with `MarkerIcon` and `MarkerContent`.

## Usage

```tsx showLineNumbers
import { Marker, MarkerContent, MarkerIcon } from "~/components/ui/marker";
```

```tsx showLineNumbers
<Marker variant="border">
  <MarkerIcon><FileTextIcon /></MarkerIcon>
  <MarkerContent>Opened implementation notes</MarkerContent>
</Marker>
```

## Variants

Use `default`, `border`, or `separator` to match the surrounding timeline or activity surface.
