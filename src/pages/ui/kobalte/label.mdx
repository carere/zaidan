## Usage

```tsx showLineNumbers

```

```tsx showLineNumbers
<Label for="email">Your email address</Label>
```

## Label in Field

For form fields, use the [Field](/docs/components/kobalte/field) component which includes built-in `FieldLabel`, `FieldDescription`, and `FieldError` components.

```tsx showLineNumbers
<Field>
  <FieldLabel for="email">Your email address</FieldLabel>
  <Input id="email" />
</Field>
```

## API Reference

`Label` is a styled native label element. See the [HTML label element reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/label) for its native props and accessibility semantics.

### Label

| Prop | Type | Default |
| --- | --- | --- |
