This update is focused on two things:

- **Image Crop** — a new composable block for image cropping. It ships the
  provider, canvas, hook, and crop helpers as the installable primitive surface,
  with avatar and full-cropper examples composed in userland.
- **Simpler Zaidan Agent** — the agent workflow now has clearer guidance for
  larger block refactors: split complex blocks into folders, keep examples out
  of the installable primitive, and list every imported block file in the
  registry.
