# Introduction

Zaidan is a collection of beautifully designed, accessible components for SolidJS and a code distribution platform built around the shadcn CLI.

**This is not a traditional component library. It is how you build your component library.**

## Open Code

Zaidan gives you the actual component source. You can customize the implementation, styling, and public API to fit your product instead of wrapping a package you do not control.

## Built for Solid

Components are written for SolidJS and use accessible primitives from Kobalte and Corvu. They follow the familiar shadcn structure while keeping Solid's reactive model and conventions.

## Distribution

Install components through the shadcn CLI, then keep the generated source in your application:

```package-dlx
shadcn@latest add @zaidan/button
```

Start with the [installation guide](/docs/installation) or browse the [components](/docs/components).
