## Build from a shared foundation

Zaidan combines accessible SolidJS components, authored implementation guidance, live examples,
and project configuration in one design-system product. Components are copied into your project
through the shadcn CLI, so the source remains yours to inspect, adapt, and maintain.

Use these guides to install the registry, customize its design tokens, add dark mode, and learn the
workflow behind Zaidan Agent. The Component Catalog is the companion reference for individual
components and blocks.
