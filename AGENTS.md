## Agent skills

### Workspace paths

Website and registry work lives in `apps/website`; factory workflows live in
`apps/factory`. Website source paths in the registry skills are relative to
`apps/website`. Run website-local tools from that directory, or use explicit
`website:<task>` Moon targets from the repository root.

### Issue tracker

Repository issues are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical engineering-workflow labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain layout. See `docs/agents/domain.md`.
